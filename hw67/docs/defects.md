# Дефекты ДЗ 6+7

1. **Смешивание runs** (`src/sweep.py`). Цикл находился внутри одного `all-candidates`: параметры логировались только для первого кандидата, последующие метрики и файлы перезаписывались. Теперь каждый кандидат имеет собственный nested run непосредственно под sweep. Общие seed, train/val, бюджет и ревизия базы закреплены.
2. **Потеря артефактов** (`compose.yaml`). PostgreSQL имел volume, а `/mlartifacts` оставался в слое контейнера. Добавлен `artifacts:/mlartifacts`. Доказательство — `make check-storage`: UUID probe, SHA256, `--force-recreate`, скачивание и сравнение. `down -v` не используется.
3. **Нет версии данных** (`src/sweep.py`). `provenance()` вычислял SHA256 train/val, но comprehension удалял все `data_*`. Теперь весь provenance сохраняется у sweep и каждого run. Снимок src, lock, config, commit и точная HF revision дополняют хеши тензоров.
4. **Обход loss gate** (`src/promote.py`). `promote()` вычислял отношение и без проверки создавал версию и alias. Теперь `gate(run, threshold)` вызывается до первой мутации реестра: FINISHED, конечные значения, положительный base loss, допустимый threshold и val/base ≤ threshold. Нулевой порог проверяется преподавательским тестом.

`evaluation/solution.py`: строгий JSON, запрет повторных ключей, сопоставление по id, сохранение ошибок в знаменателе. Quality gate проверяет provenance протокола, полноту, конечность и соответствие counts каждой строке, одинаковые id и членство в срезах, отсутствие ошибок, общие/критические регрессии и все behavioral-кейсы. Синтетический `kind=fixture` оставлен для исходных тестов; штатный CLI дополнительно сверяет конкретные версии моделей и пересчитывает отчёты из raw.

Все исходные файлы `tests/` сохранены без изменений.
