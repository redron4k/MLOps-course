# ДЗ 6+7: Android-адаптер

Протокол закреплён до генерации. Продолжаем ДЗ 4–5: Qwen3-0.6B, исходные train/val без ретокенизации, шесть конфигураций по четыре шага, train pool 32, val 8, batch 1 × accumulation 2, seed 42. Выбор только по val loss, затем val/base ≤ 1.0. Golden не используется для подбора кандидата.

Срезы golden: `ui-recyclerview`, `ui-dialog`, `services`, `firebase-auth`, `firebase-messaging` — по 10 авторских вопросов. Эти группы исключены из train в ДЗ 3 и сохранены под теми же именами. UI важен для практических Android-ответов; сервисы проверяют понимание жизненного цикла фоновых компонентов; авторизация и push — границы клиентского API. `services` и `firebase-auth` критические: ошибки исполнения и идентификации особенно существенны. Регрессия общей accuracy/format_rate и критических срезов недопустима, все три behavioral-кейса обязательны.

Вопросы составлены агентом по официальной документации, метки сверены с источниками. Проверку человеком не имитируем: перед сдачей нужен человеческий просмотр разметки. Полный train-index экспортируется из 1222 исходных записей; 1221 из них сохранилась после маски/обрезки ДЗ 4. Совпадение нормализованных текстов и group_id проверяет обвязка; это не доказательство отсутствия всех смысловых пересечений. Темы относятся к прежним отложенным группам ДЗ 3, поэтому этот golden уже нельзя называть независимым final audit.

Результаты реального запуска будут добавлены после sweep и оценки. Порог и состав критических срезов после просмотра ответов не меняются.
